# Archived progress reports

These files were generated during an earlier, breadth-first phase of the project.
They describe an idealized, "everything complete" version of DanteGPU that does not
match the code. They claim finished work (full 2FA, OAuth2, smart contracts,
Stripe/PayPal, a complete mobile app, full billing integration) that the audit
behind the current README showed to be stubbed, partial, or absent.

They are kept for history only. **Do not treat anything here as a description of
current behavior.** For that, read:

- [../../README.md](../../README.md): what the system actually does
- [../STATUS.md](../STATUS.md): per-service reality
- [../../ROADMAP.md](../../ROADMAP.md): what is planned and in what order
